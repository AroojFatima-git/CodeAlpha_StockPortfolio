# 📈 CodeAlpha Stock Portfolio Tracker

A simple Python application that calculates total investment based on manually defined stock prices and user-entered quantities.

## 📌 Features

- Display available stocks
- Enter stock symbols and quantities
- Calculate individual investments
- Calculate total investment
- Input validation
- Export portfolio to CSV

## 🛠️ Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Exception handling
- CSV file handling

## ▶️ How to Run

```bash
python stock_tracker.py
